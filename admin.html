Important setup notes

  • This page uses Supabase Authentication and Storage. It does not create an admin account automatically.
  • Your Supabase Storage policies must permit authenticated administrators to upload, list, update, and delete files.
  • Never put a Supabase service-role key or secret key in this HTML file.
  • After uploading, open the website and refresh it to check the changes.
